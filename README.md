# GHOST HUNT — ¡Atrapa los fantasmas!

GHOST HUNT* es un videojuego interactivo con temática de Halloween, desarrollado con JavaScript y p5.js. El objetivo principal es atrapar la mayor cantidad de fantasmas posible haciendo clic sobre ellos antes de que se termine el tiempo.

##  Descripción del proyecto

En GHOST HUNT, el jugador debe demostrar su rapidez y precisión para capturar fantasmas que aparecen aleatoriamente en diferentes posiciones de la pantalla.

El juego cuenta con una ambientación inspirada en Halloween, utilizando colores oscuros, una luna, siluetas de edificios y fantasmas diseñados mediante figuras geométricas.

La experiencia está diseñada para ser sencilla, entretenida y fácil de jugar.

## ¿Cómo jugar?

1. Inicia el juego haciendo clic en la pantalla.
2. Observa dónde aparece el fantasma.
3. Haz clic sobre el fantasma para atraparlo.
4. Cada fantasma atrapado suma un punto.
5. Intenta conseguir la mayor puntuación posible antes de que termine el tiempo.

**Duración de cada partida:** 30 segundos.

## Características principales

- Aparición aleatoria de fantasmas.
- Sistema de puntuación.
- Temporizador de 30 segundos.
- Opción para volver a jugar.
- Ambientación visual de Halloween.
- Interfaz sencilla e interactiva.

## Tecnologías utilizadas

- **JavaScript:** lógica y funcionamiento del videojuego.
- **p5.js:** creación de gráficos, animaciones y detección de interacciones.
- **HTML5:** estructura para ejecutar el juego en el navegador.

##  Objetivo del proyecto

Crear un videojuego pequeño e interactivo que combine programación, creatividad y entretenimiento, aplicando conceptos fundamentales de JavaScript, como variables, funciones, condicionales, objetos, eventos del mouse y generación de posiciones aleatorias.

## Aprendizajes

Durante el desarrollo de GHOST HUNT se aplicaron conocimientos de:

- Programación estructurada.
- Manejo de eventos del mouse.
- Uso de funciones y variables.
- Generación de elementos aleatorios.
- Control del tiempo mediante `millis()`.
- Creación de gráficos con p5.js.
